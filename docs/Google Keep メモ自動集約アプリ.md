# Google Keep メモ自動集アプリ仕様書

## 1. システム概要
本システムは、個人のGoogleアカウント（`@gmail.com`）において、Google Keep上のリストメモ（「読書」「ショッピング」「生活」など）の内容を抽出し、Googleドライブ内の同名フォルダ配下のGoogleドキュメントへ1日1回追記・整理して、元のKeepメモを空にするPythonバッチツールである。

---

## 2. 動作環境・構成
* **OS:** Windows 11 
* **Pythonバージョン:** Python 3.13以上
* **実行環境:** プロジェクト配下に作成した仮想環境（`venv`）
* **利用主要ライブラリ:**
  * `gkeepapi` (Google Keep同期)
  * `google-api-python-client`, `google-auth-httplib2`, `google-auth-oauthlib` (Drive/Docs API)
  * `python-dotenv` (環境変数・認証情報管理)

---

## 3. ディレクトリ・パス設計

スクリプト起動方式のため、設定ファイルやトークンの読み書きは **「スクリプトファイル（`main.py`）が存在するディレクトリ（`Path(__file__).resolve().parent`）」** を基準パスとする。

## 4. 認証・セキュリティ設計

認証情報は.envファイルで管理する。

### 4.1 Google Keep (`gkeepapi`)
1. `.env` に記載されたGoogleアカウント・アプリパスワードを取得。
2. 同一階層の `.gkeep_token` を確認。存在する場合はトークンログイン、存在しない場合は初回ログイン後にトークンを書き出し保存。

### 4.2 Google Drive & Docs API (OAuth 2.0)
1. 同一階層の `credentials.json` をロード。
2. 同一階層の `token.json` が有効であれば再利用。
3. 初回実行時のみローカルサーバーを起動し、ブラウザで認証（`InstalledAppFlow`）。

---

## 5. 処理フロー

```
[開始: main.py (または run.bat) 起動]
  │
  ├─ 1. スクリプト配置ディレクトリの特定とログ初期化
  │
  ├─ 2. Keep / Drive / Docs APIの認証
  │
  ├─ 3. Keep内の全リストメモを走査
  │     └─ タイトルが存在し、かつアイテム数が1件以上のメモを抽出
  │
  ├─ 4. 各メモに対して以下を実行:
  │     │
  │     ├─ (a) メモ内アイテムの取得・ソート（並べ替え）
  │     ├─ (b) ドライブ内の同名フォルダを検索（無ければ作成）
  │     ├─ (c) フォルダ内の同名ドキュメントを検索（無ければ新規作成してフォルダ内へ配置）
  │     ├─ (d) ドキュメント末尾へフォーマット済みテキストを追記
  │     └─ (e) 成功確認後、Keepメモ内のアイテムを全削除（空リスト化）
  │
  ├─ 5. Keepの変更をリモートへ同期 (keep.sync())
  │
[終了: ログ出力してプロセス終了 (Exit Code 0)]
```

---

## 6. データ処理・並べ替えルール

チェックボックスなどはつけず、アイテム名(リストの内容)のみを入れる。

### 6.1 ソート順
1. **第1優先:** アイテム作成/更新日時（新しい順・降順）
2. **第2優先:** テキスト辞書順（五十音・アルファベット昇順）

### 6.2 Googleドキュメント追記フォーマット
```markdown
アイテム名1
アイテム名2
アイテム名3
```

---

## 7. セットアップ実行ラッパー仕様

### 7.1 起動用バッチファイル (`run.bat`)
タスクスケジューラ等からの自動実行時、仮想環境内のPythonインタープリタを確実に呼び出すため、プロジェクトルートに `run.bat` を配置する。

```bat
@echo off
cd /d %~dp0
call .venv\Scripts\python.exe main.py
```

---

## 8. 定期実行仕様（Windows タスクスケジューラ）

Windowsタスクスケジューラへの設定は後で手動で行う。

* **トリガー:** 毎日指定時刻（例: `23:00`）
* **操作（設定方法 A: `run.bat` を呼び出す場合 - 推奨）:**
  * プログラム/スクリプト: `C:\Path\To\KeepSyncApp\run.bat`
  * 開始（オプション）: `C:\Path\To\KeepSyncApp\`
* **操作（設定方法 B: `pythonw.exe` でバックグラウンド実行する場合）:**
  * プログラム/スクリプト: `C:\Path\To\KeepSyncApp\.venv\Scripts\pythonw.exe`
  * 引数の追加: `main.py`
  * 開始（オプション）: `C:\Path\To\KeepSyncApp\`
* **条件:** 「コンピューターをAC電源で使用している場合のみタスクを開始する」のチェックを外す。
